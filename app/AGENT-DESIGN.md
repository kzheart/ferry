# Agent 对话体验调整（2026-09-06）

## 参考与取舍

通过电脑工具在 Chrome 实际浏览 Inspora Product 分类，重点观察两个动态作品。浏览器标签工具曾超时，随后使用原生 Chrome 操作完成查看。

- [AI Agent Approval Cards — @kvnkld](https://www.inspora.design/posts/1-37)：连续观察 30 秒，覆盖问题选择、补充文本、问题切换、计划展开/收起与循环重播。借鉴紧凑选项、主次动作、按需展示细节；Ferry 回答后保留可展开记录。作品中的自动批准倒计时不移植。
- [Agent Handoff — @jeetnirnejak](https://www.inspora.design/posts/1-48)：连续观察 22 秒，覆盖阶段交接、日志追加、暂停/恢复、完成与重播。借鉴当前活动与历史记录的区分；不虚构 Ferry 没有的四阶段流程或进度百分比。

## 实现

- **开始任务**：空态说明实际能力，三个建议仅填入草稿，由用户决定是否发送。
- **输入**：减小圆角与阴影，区分编辑区、模式/模型、主动作和辅助提示；正文随实际换行增高，上限 180px；排队发送与转向分别说明。中文输入法确认候选词不触发发送。
- **运行**：输入区上方显示等待回答、等待审批、执行工具或处理中；工具行使用可键盘操作的按钮，细节按需展开。
- **提问**：问题为主，推荐、多选和描述为辅助；提交中保留反馈，失败后保留选择。回答后显示问题和答案摘要，展开为只读记录，去掉粗彩条与禁用表单。
- **过渡**：提问卡片高度变化使用 170ms 过渡，连续操作取消旧动画并接续当前高度；尊重减少动画偏好。
- **审批**：统一细边框与信息层级，保留风险和影响范围；到期即时移除动作，点击时再校验截止时间，不自动批准。
- **失败与停止**：错误分为简短原因、下一步提示和折叠的原始详情；没有自动重试或可能重放副作用的按钮。停止与上下文整理保留轻量状态行。
- **回看**：上翻历史不抢滚动位置，提供回到最新消息按钮；切换会话重置跟随状态。

## 验证

前端完整测试 405 项通过；后续卡片动效调整的 9 项聚焦测试、类型检查、模块边界、diff 检查和 macOS debug 构建通过。

电脑实际验证新对话建议填入草稿、提问选择/提交/完成记录展开、错误详情、回到最新、长文本高度上限、较窄窗口及深色主题。提问使用临时本地可控模型后端，Runtime 与宿主交互为真实链路；测试后已关闭后端，恢复系统主题并清空草稿。审批到期、输入法与滚动逻辑另有自动化回归覆盖。

未把此次 UI 验收当作真实模型连通性、多提供商、迁移或所有工具能力的重新验收。
